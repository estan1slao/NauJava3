# Создание администратора
В приложении используется Spring Security. После обычной регистрации пользователь получает роль `USER`. Чтобы предоставить пользователю права администратора, сначала зарегистрируйте его через приложение, а затем измените его роль в базе данных PostgreSQL.

## 1. Запустите приложение

## 2. Зарегистрируйте пользователя

1. Откройте страницу [http://localhost:8080/registration](http://localhost:8080/registration).
2. Заполните форму регистрации.
3. Запомните указанный логин и пароль.
4. После регистрации войдите под созданной учётной записью.

На этом этапе пользователь имеет обычную роль `USER`.

## 3. Откройте базу данных `personal_expenses` в pgAdmin 4

## 4. Назначьте роль ADMIN

Вставьте SQL-запрос ниже. Замените `admin` на логин зарегистрированного пользователя. Логин должен точно совпадать с указанным в форме регистрации.

```sql
-- Добавляем столбец роли, если его ещё нет.
ALTER TABLE app_users
    ADD COLUMN IF NOT EXISTS role VARCHAR(20);

-- Назначаем USER всем существующим пользователям без роли.
UPDATE app_users
SET role = 'USER'
WHERE role IS NULL OR role = '';

-- Назначаем администратора выбранному пользователю.
UPDATE app_users
SET role = 'ADMIN'
WHERE username = 'admin';

-- Проверяем результат.
SELECT id, username, role
FROM app_users
ORDER BY id;
```

## 5. Войдите заново

После изменения роли:

1. Выйдите из приложения.
2. Войдите повторно под учётной записью, которой назначена роль `ADMIN`.

## 6. Проверьте права администратора

Откройте Swagger UI:

[http://localhost:8080/swagger-ui/index.html](http://localhost:8080/swagger-ui/index.html)

Пользователь с ролью `ADMIN` должен иметь доступ к Swagger UI. Пользователь с ролью `USER` не должен иметь к нему доступа.
