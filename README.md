# Практическая работа №7

## Что добавлено

Реализована генерация финансовых отчётов с использованием многопоточности и асинхронного выполнения.

Добавлены:
- Асинхронное формирование отчётов.
- Параллельная обработка данных в отдельных потоках.
- Сохранение отчётов в базе данных.
- Отслеживание статуса формирования отчёта.
- REST API для создания и получения отчётов.
- Отдельная HTML-страница `/reports` для запуска генерации и проверки результата.

## Как проверить работу

1. Запустить PostgreSQL и приложение.
2. Открыть в браузере страницу:

   `http://localhost:8080/reports`

3. При необходимости авторизоваться.
4. Нажать кнопку **«Создать отчёт»**.
5. Дождаться завершения формирования отчёта. Статус обновляется автоматически.
6. После завершения нажать на ссылку **«Открыть отчёт в новой вкладке»**.
7. Убедиться, что открылся сформированный HTML-отчёт.

## API

- `POST /api/reports` — создать отчёт.
- `GET /api/reports/{id}` — проверить статус или получить готовый отчёт.

Готовый отчёт открывается по адресу:

`http://localhost:8080/api/reports/{id}`
