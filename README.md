## Настройка базы данных

Создать базу данных `personal_expenses` в PostgreSQL.

Настроить переменную окружения `DB_PASSWORD`, содержащую пароль пользователя PostgreSQL.

Параметры подключения задаются в `src/main/resources/application.properties`.
